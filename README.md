# koishi-plugin-huaji-xiuxian

群聊修仙文字 MUD，由 [nonebot-plugin-xiuxian-2](https://github.com/luolianxiyou/nonebot-plugin-xiuxian-2) 移植并重构为 Koishi 插件。

当前版本：**0.6.4**

## 依赖

| 服务 | 必需 | 说明 |
|------|------|------|
| `database` | 是 | 玩家、背包、宗门等数据 |
| [monetary](https://koishi.chat/market?keyword=monetary) | 是 | 灵石经济 |
| [markdown-to-image-service](https://www.npmjs.com/package/koishi-plugin-markdown-to-image-service) | 否 | 长文本转图片（可选，基于 Puppeteer，已内嵌中文字体） |

## 快速开始

1. 在 Koishi 控制台启用本插件
2. 发送 **我要修仙** 创建角色
3. 发送 **修仙帮助** 查看指令

## 配置指引（新手必看）

启用插件后，按以下步骤即可开玩，无需通读下方更新历史：

1. **必装服务**：确保 Koishi 已安装并启用 `database` 与 `monetary`（灵石经济依赖它）。
2. **群聊范围（白名单）**：
   - 默认**所有群都响应**；若只想在指定群游玩，在「基础设置 → 群聊白名单」开启开关并填入群 ID。
   - **官方 QQ 机器人（adapter-qq）**：群 ID 不是数字群号，而是一串 `group_openid`。在目标群发送 `@机器人 群组信息`（需管理员权限），复制返回的「群ID（填白名单用）」填入。
   - OneBot / Napcat：填纯数字群号即可。
   - 多群每行一个；**列表为空则所有群静默不响应**。
3. **指令面板（仅 adapter-qq）**：在「QQ 指令面板」开启 `enablePanel`，机器人连上后自动在群聊配置快捷指令面板（可选）。
4. **娱乐小游戏**：在「娱乐小游戏」分组可分别开关 `金银阁` 与 `虚神界对决`（默认开启）。
5. 黑名单 `userBlacklist`：填 QQ 号 / openid，列表中的用户无论公私聊都不响应（无需开白名单即生效）。

> 管理指令（`authority >= 999`，如 `群组信息`、`配置面板`、`神秘力量`、`重置状态`、`创建世界boss`、`系统坊市上架`）**豁免白名单**，可在任意群执行，但仍受黑名单约束。

## 娱乐小游戏

### 金银阁·猜大小

`金银阁` → 先回复**大**或**小**，再回复押注灵石数，掷 3 颗骰子定胜负：

- 点数和 **4–10 为小**、**11–17 为大**
- **三颗同点（豹子）庄家通杀**，押注尽归金银阁
- 押中按 **1.9 倍**返还（净赚 0.9 倍），押错全扣
- 限制：30 秒冷却 + 每日次数上限（默认 50）+ 单次 / 每日灵石上限（见配置）

### 虚神界对决 / 俄罗斯轮盘

`虚神界对决 @对方 <灵石数>` 发起，**对方发 `接受对决` 确认**后开打：

- 双方灵石在「接受」时锁定；模拟 6 轮轮盘（6 膛 1 发真弹，轮流开枪），**必有一方暴毙**
- **胜者通吃双方押注**（得 2 倍押注，净赚 1 倍）
- 限制：每人每日发起次数上限（默认 3）+ 对方接受超时（默认 120 秒，超时自动取消且双方灵石不扣）

| 配置项 | 默认 | 说明 |
|--------|------|------|
| `enableJinyinge` | `true` | 是否开启金银阁 |
| `jinyinDailyLimit` | `50` | 金银阁每日次数上限 |
| `jinyinSingleLimit` | `100000000` | 金银阁单次押注上限 |
| `jinyinDailyStoneLimit` | `500000000` | 金银阁每日累计押注上限 |
| `jinyinCd` | `30` | 金银阁冷却（秒） |
| `enableVoidDuel` | `true` | 是否开启虚神界对决 |
| `voidDuelDailyLimit` | `3` | 虚神界对决每日发起次数上限 |
| `voidDuelAcceptTimeout` | `120` | 对方接受超时（秒） |

## 0.6.3 更新摘要

### 适配官方 QQ 机器人（adapter-qq）的群聊白名单

官方 QQ 群机器人的群标识是 **`group_openid`**（一串不透明字符串，并非纯数字群号）。此前白名单若仍填旧的数字群号，开启后会导致所有群被静默拦截、机器人「不响应」。

- 新增管理指令 **`群组信息`**（别名 `群信息`，`authority >= 999`，豁免白名单）：在任意群内执行即可回显当前的 `group_openid`、你的用户 ID 与机器人自身 ID，**复制其中的「群ID（填白名单用）」加入群聊白名单即可放行**
- 白名单开启且某群未命中时，控制台新增**去重日志**，提示被静默拦截的群 `guildId`，便于回填
- 白名单匹配逻辑本身已兼容任意字符串（数字群号 / openid / 带 `qq:` 前缀），无需改动
- `package.json` 新增 `prepublishOnly: tsc -b`，杜绝 `lib/` 陈旧构建被发布

> 迁移提示：从 napcat(onebot) 切到官方 QQ 机器人后，群聊白名单请改用各群的 `group_openid`（用 `群组信息` 指令获取），旧数字群号不再生效。

- 设置面板的白名单开关与列表字段现已内置**填写指引**（OneBot 填数字群号 / 官方机器人填 openid / 多群每行一个 / 管理指令豁免），新用户无需看文档也能填对

### 建号引导：加入宗门支持回复序号

新手引导在选择系统宗门时，原先只能回复**宗门全名**。现改为面板中显示的**序号（1 基）或宗门全名**均可加入：

- 玩家回复 `1`/`2`/`3`/`4` 等序号即可加入对应预设宗门（带前后空格也能识别）
- 仍支持回复宗门全称；序号越界或空白会提示重新输入，不再误判为全名

> 注意：建号引导里的「序号」是预设宗门列表的序号（1~N）；常规 `加入宗门 <编号>` 指令的「编号」是宗门在数据库中的 `sectId`，两者含义不同、互不通用。

### QQ 群「指令面板」自动配置（adapter-qq）

官方 QQ 机器人支持在群聊配置「指令面板」（API：`POST/PUT /v2/panels`，`scope=group`），玩家点击即可把指令填入聊天框。本插件可自动在 adapter-qq 机器人上配置该面板，无需手动调 API。

- 新增管理指令 **`配置面板`**（别名 `推送面板`，`authority >= 999`，豁免白名单）：在任意群执行即（重新）推送面板到所有官方 QQ 机器人；也可用于配置变更后手动修复
- 插件启动 / adapter-qq 机器人连上后**自动推送一次**（延迟 3s 等 token 就绪），开关见下方 `enablePanel`
- 面板条目：默认内置 12 条常用指令；可在设置面板「指令面板条目」文本框中按需覆盖 / 增删（每行一条指令名，即点击后填入聊天框的文本，上限 20 条）
- 目标群：白名单开启时只推送到白名单群（`target_type=specific`，超过 20 个群自动拆成多个面板）；白名单关闭时推送到全部群（`target_type=all`）
- 面板以固定 `remark=xiuxian-panel` 认领，重复推送走 `PUT` 更新而非新建；白名单缩减后会自动删除多余旧面板

| 配置项 | 默认 | 说明 |
|--------|------|------|
| `enablePanel` | `true` | 是否自动配置 QQ 群指令面板（仅官方 QQ 机器人 adapter-qq 生效；OneBot/Napcat 无需开启） |
| `panelEntries` | `''` | 指令面板条目，每行一条指令名（点击后填入聊天框的文本）；留空则用内置默认 12 条 |

> 注意：官方 QQ 机器人在群聊中通常只接收 `@机器人` 的消息。面板 `command` 按钮点击后是否自动 `@` 取决于平台行为；若某群点击面板无响应，请确认平台已自动 `@`，或改用单聊「自定义菜单」（本插件暂未封装单聊菜单，可手动调 `PUT /v2/menu`）。

## 0.6.2 更新摘要

### 群聊白名单与黑名单

控制台「基础设置」新增四项，限制机器人仅在指定群游玩：

| 配置项 | 默认 | 说明 |
|--------|------|------|
| `groupWhitelistEnabled` | `false` | 群聊白名单开关 |
| `groupWhitelist` | `[]` | 白名单 QQ 群号列表（纯数字）。开关开启时生效；**列表为空则所有群均不响应** |
| `allowPrivateChat` | `false` | 白名单开启时是否也响应私聊（默认仅响应白名单群） |
| `userBlacklist` | `[]` | QQ 号黑名单：列表中的用户无论私聊/群聊均不响应（无需开启白名单即生效） |

行为要点：

- 开启白名单后，**仅在白名单群内的消息会得到响应**；非白名单群与（默认）私聊一律**静默忽略**（不回复任何消息）
- 群号按「去除平台前缀后的数字」匹配（如 `qq:123` 与 `mock:123` 均视作 `123`），便于跨平台与测试
- **管理指令（`authority >= 999`，如 系统坊市上架、重置状态、创建世界boss、神秘力量）豁免白名单**，仍可在任意群执行，但同样受黑名单约束
- **定时任务（坊市自动补货、过期下架）仅处理白名单内群**，移出白名单的群不再被自动维护

## 0.6.0 更新摘要

### 洞天经营玩法

- **开辟洞府**：耗灵石开辟个人洞府（可自定义名称，缺省自动命名），自动获赠灵田 1 块
- **灵气升级**：耗灵石提升洞府灵气等级（1~5 级），每级提升闭关修为收益与成熟收成
- **灵田种植 / 灵田收获**：消耗背包 1 份药材种到空闲灵田（交互选序号），越稀有成熟越久；收获按灵气等级随机获得 2~8 份（不凭空得药材）

- **洞府信息 / 洞府帮助**：查看灵气、灵田概况与玩法说明
- **洞府改名 <名称>**：耗灵石为洞府更名（最长 12 字，每次 10000 灵石）

### 转世气运

- **飞升转世**：满级玩家可转世，重置境界换取转世次数与专属称号

- 转世「气运加身」：转世次数越高，越易参悟天机、突破瓶颈，寻觅机缘时更易获珍稀之物
